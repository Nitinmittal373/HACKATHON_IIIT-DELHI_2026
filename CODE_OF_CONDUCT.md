# Code of Conduct

We want NeevCheck to be a friendly project for everyone who uses or improves it.

**We expect you to**

- be respectful and kind in issues, reviews and discussions
- give feedback about the code, never about the person
- assume good intent and ask before you judge

**We do not accept**

- harassment, insults or discriminatory language
- publishing other people's private information
- sharing anyone's API keys or credentials

If something goes wrong, contact the maintainers listed in [CONTRIBUTING.md](CONTRIBUTING.md).
They will review every report and may remove content or block accounts that break these rules.
